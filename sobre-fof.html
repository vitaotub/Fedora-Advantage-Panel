👋 Sobre o Fedora Only Fans

📌 O que é o FOF

O Fedora Only Fans (FOF) é um painel de automação visual para configurar o Fedora Linux. Ele reúne, numa interface amigável, os passos que normalmente exigiriam comandos no terminal — do ajuste inicial do sistema até deixar tudo pronto para o uso diário e para jogos.

🎯 Por que ele foi criado

O Fedora é excelente, mas exige alguns passos iniciais (ativar RPM Fusion, instalar codecs, configurar drivers) que costumam intimidar quem vem de distribuições como Ubuntu, Linux Mint ou Zorin OS. O FOF automatiza esses passos e os apresenta de forma clara, em sessões guiadas — sem que você precise lembrar comandos ou pesquisar tutoriais.

✅ O que você ganha

Com o FOF, você deixa seu Fedora completo em poucos cliques: codecs multimídia, repositórios essenciais, drivers AMD/NVIDIA, aceleração gráfica, suporte a jogos (Steam, Heroic, Lutris, Proton), ferramentas de produtividade, apps de internet, edição de áudio e vídeo, e muito mais. Tudo isso com logs em tempo real e sem precisar abrir o terminal.

⚠️ O que o FOF não faz

  • Não substitui o terminal — quando algo dá errado, alguns problemas ainda exigem comandos manuais para diagnóstico.
  • Não instala jogos — ele prepara o sistema para você instalar e rodar jogos, mas não baixa nem instala jogos em si.
  • Não faz backup dos seus dados — recomendamos sempre ter snapshots ou backup antes de alterações no sistema.
  • Não é afiliado à Red Hat — é um projeto independente, mantido pela comunidade.
  • Não é um instalador de sistema operacional — o FOF configura um Fedora já instalado, não instala o Fedora do zero.
🔧 Manutenção do FOF
⬆️ Uma nova versão do FOF está disponível. Clique em "Atualizar FOF" abaixo para instalar.

🔄 Atualizar Fedora Only Fans

Baixa e instala a versão mais recente do FOF diretamente do GitHub. Mantenha seu app sempre atualizado!

ℹ️ A atualização mantém suas configurações e histórico.

🗑️ Desinstalar Fedora Only Fans

Remove completamente o FOF do seu sistema, incluindo todos os arquivos, configurações e atalhos.

⚠️ ATENÇÃO: Esta ação é irreversível! Todos os dados do FOF serão removidos.
