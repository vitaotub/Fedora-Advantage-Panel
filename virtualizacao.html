Sessão 🖥️ Virtualização
Ferramentas para executar máquinas virtuais no Fedora. Cada opção atende um perfil diferente de uso — QEMU/KVM é a stack nativa (mais performática), VirtualBox oferece uma interface familiar para quem vem do Windows, e GNOME Boxes simplifica a experiência para iniciantes.
🖥️ Máquinas Virtuais

QEMU/KVM + virt-manager

Stack de virtualização nativa do Linux. Roda máquinas virtuais com aceleração por hardware via KVM — é a opção mais performática e a base de todas as outras soluções. Instala o QEMU, o daemon libvirt, o virt-manager (interface gráfica) e habilita o serviço do sistema.

ℹ️ Sobre permissões: seu usuário é adicionado ao grupo libvirt para gerenciar VMs sem precisar de senha em cada ação. O grupo só entra em vigor após logout/login — até lá, o virt-manager vai pedir a senha de administrador ao abrir.

VirtualBox

Software de virtualização multiplataforma da Oracle. Boa opção para quem já conhece o VirtualBox de outras plataformas. Requer o RPM Fusion (Sessão 1) para o módulo de kernel akmod-VirtualBox, que recompila automaticamente a cada kernel novo.

ℹ️ QEMU/KVM vs VirtualBox: ambos rodam máquinas virtuais, mas QEMU/KVM é mais performático no Linux (integração nativa com o kernel). VirtualBox é preferível quando você já tem discos virtuais no formato .vdi ou depende de recursos específicos dele.

GNOME Boxes

Interface gráfica simplificada para criar e gerenciar máquinas virtuais. Usa QEMU/KVM por baixo, então é performático como o virt-manager — a diferença está na experiência: em vez de configurar CPU, RAM e disco separadamente, você aponta para um arquivo .iso e ele cuida do resto.

ℹ️ Recomendado para: quem está começando com virtualização e quer testar uma distribuição Linux ou o Windows sem configurar nada manualmente. Se você já tem experiência, prefira o virt-manager — oferece mais controle sobre a VM.
