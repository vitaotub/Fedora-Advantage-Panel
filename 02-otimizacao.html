Corrigir problemas de data/hora em Dual-Boot (Windows/Linux)

Faz o Fedora usar o relógio em horário local (igual o Windows faz por padrão), resolvendo o problema de horário errado ao alternar entre os sistemas.

💡 Por padrão, o Windows grava o horário do hardware em horário local, enquanto o Linux (Fedora) grava em UTC. Quando você alterna entre os dois, cada sistema interpreta o relógio de forma diferente e o horário aparece errado. Este botão configura o Fedora para usar horário local, alinhando o comportamento com o do Windows — assim você não precisa mexer em nada no Windows.

Ajustes de Memória para Jogos e Aplicações Pesadas

Aumenta o número máximo de áreas de memória que cada processo pode mapear. O valor padrão do Fedora é 65530, que é insuficiente para jogos modernos e aplicações pesadas — vários títulos falham ao iniciar ou travam por falta de memória mapeável (Hogwarts Legacy, Counter-Strike 2, The Finals, Star Citizen, entre outros).

ℹ️ O que muda: o limite sobe de 65.530 para 2.147.483.642 (o máximo prático). É uma correção de compatibilidade, não um "tweak" — o valor antigo causa falhas reais.

Uso Inteligente de Memória e Cache

Ajusta dois parâmetros do kernel que controlam como o sistema usa swap e cache de arquivos. O Fedora vem com valores conservadores que priorizam o disco; esses ajustes fazem o sistema manter mais RAM disponível para as aplicações em primeiro plano e reter por mais tempo caches de disco, o que melhora a sensação de velocidade em tarefas do dia a dia.

ℹ️ O que muda:
• vm.swappiness: de 60 (padrão) para 150 — sistema usa swap de forma mais proativa.
• vm.vfs_cache_pressure: de 100 (padrão) para 50 — kernel retém mais tempo os caches de arquivos.
Ambos os valores são seguros para a maioria dos desktops. Se você usa um SSD e se preocupa com o desgaste, pode reverter depois.

Aceleração de Rede com TCP BBR

Substitui o algoritmo de controle de congestionamento do TCP padrão (cubic) pelo BBR, desenvolvido pelo Google. Ele melhora a latência e a vazão em conexões com perda de pacotes, o que beneficia jogos online, streaming e downloads. É um dos poucos ajustes de rede que trazem ganho consistente sem configuração manual.

ℹ️ O que muda:
• net.core.default_qdisc: de fq_codel para fq (necessário para o BBR).
• net.ipv4.tcp_congestion_control: de cubic para bbr.
Não requer reinicialização — o efeito é imediato após aplicar.
