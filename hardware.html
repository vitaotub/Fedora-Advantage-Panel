🟥 Hardware AMD
ℹ️ Os drivers AMD são todos de código aberto. Os botões abaixo instalam os complementos que o Fedora não traz por padrão: Vulkan 32-bit (necessário para Steam/Proton rodando jogos de 32 bits) e VA-API via RPM Fusion (para aceleração de vídeo sem os codecs restritos por licenciamento). O Fedora base já traz as versões 64-bit de Vulkan/Mesa e o VA-API padrão. Não há botão de remoção — o dnf remove desses pacotes cascatearia para o Steam e outros apps. Para desfazer, use o terminal e aceite os dependentes.

Vulkan, Mesa 3D e RADV

Instala as bibliotecas Vulkan (versões de 32 e 64 bits), o Mesa 3D com o driver RADV (drivers Vulkan open-source da AMD), ferramentas de diagnóstico e drivers de compatibilidade. Essencial para Steam, Proton e jogos nativos.

VA-API (Aceleração de Vídeo)

Instala os drivers de aceleração de vídeo por hardware (VA-API) do RPM Fusion, que substituem os drivers padrão do Fedora para GPUs AMD. Necessário para reprodução fluida de vídeo em HD/4K e para encoding via GPU. O RPM Fusion (Sessão 1) é pré-requisito.

ℹ️ O que é instalado: mesa-va-drivers-freeworld (VA-API), ffmpeg-libs, libva e libva-utils. O Fedora mantém o suporte de aceleração bloqueado por licenciamento no Mesa padrão. Nota: o VDPAU foi removido do Fedora 44 em diante; não há mais pacote mesa-vdpau-drivers-freeworld.

🟩 Hardware NVIDIA
⚠️ O driver proprietário da NVIDIA exige que o parâmetro nvidia-drm.modeset=1 esteja ativo para o Wayland funcionar corretamente. O RPM Fusion (Sessão 1) é pré-requisito. Após instalar o driver, o computador precisa ser reiniciado.
⚠️ Driver proprietário indisponível para sua GPU
A série detectada para sua GPU (—) exige o servidor gráfico Xorg, mas o Fedora 44+ não oferece mais Xorg de forma oficial — apenas Wayland. Por isso o FAP não instala drivers das séries 470xx ou 390xx. Continue usando o driver nouveau (código aberto, já incluído no Fedora).

Driver Proprietário Completo (CUDA + NVENC/NVDEC)

Detecta a geração da sua GPU NVIDIA e instala automaticamente a série de driver correta — akmod-nvidia para Turing e mais recentes, akmod-nvidia-580xx para Maxwell/Pascal, akmod-nvidia-470xx para Kepler e akmod-nvidia-390xx para Fermi. Inclui os suplementos CUDA + bibliotecas NVENC/NVDEC para OBS, Kdenlive e encoding por hardware.

ℹ️ Sobre a detecção: o FAP lê o modelo da GPU via lspci (com nvidia-detect como fonte primária quando disponível) e escolhe o pacote correto. Instalar a série errada resulta em tela preta após o reboot — esta detecção evita esse problema. Se nenhuma GPU NVIDIA for encontrada, o comando aborta com uma mensagem clara e nada é instalado.

Aceleração de Vídeo por Hardware (VA-API via NVIDIA)

O driver proprietário da NVIDIA não expõe VA-API nativamente — ele usa a API concorrente VDPAU. O pacote libva-nvidia-driver é uma camada de tradução: recebe as chamadas VA-API dos aplicativos (Firefox, Chrome, VLC, etc.) e as converte para o chip NVDEC da NVIDIA. Sem ele, a aceleração de vídeo no navegador não funciona.

ℹ️ O que é instalado: libva-nvidia-driver (o tradutor), libva-utils (contém o vainfo), vdpauinfo (verificador VDPAU) e gstreamer1-vaapi (integração com GStreamer).

Utilitários de Verificação (libva-utils + vdpauinfo + gstreamer1-vaapi)

Instala as ferramentas de diagnóstico libva-utils (contém o vainfo), vdpauinfo (equivalente ao vainfo, mas para VDPAU) e gstreamer1-vaapi (integração com GStreamer). Sem esses pacotes, você não consegue verificar se a aceleração está funcionando.

Configurar Variáveis de Ambiente (VA-API)

Cria o arquivo ~/.config/environment.d/99-fap-nvidia-vaapi.conf com as variáveis necessárias para o libva-nvidia-driver funcionar: NVD_BACKEND=direct, LIBVA_DRIVER_NAME=nvidia e MOZ_DISABLE_RDD_SANDBOX=1. O arquivo é do seu usuário (não do sistema) — pode ser removido a qualquer momento clicando em "Reverter".

ℹ️ Sobre a reversão: o botão "Reverter" apaga apenas o arquivo 99-fap-nvidia-vaapi.conf. Seus outros arquivos em ~/.config/environment.d/ não são tocados. O efeito só é aplicado após logout/login.

🟦 Hardware Intel
⚠️ Estes pacotes são para iGPUs Intel (gráficos integrados). Se você tem GPU dedicada AMD ou NVIDIA, o driver da placa dedicada cuida da maior parte da aceleração — os drivers Intel ainda podem ser úteis se você usa a iGPU em conjunto, mas não são obrigatórios.
ℹ️ Os drivers Intel são todos de código aberto. Os botões abaixo instalam os complementos para aceleração de vídeo que o Fedora não traz (ou traz em versão mais antiga): Intel Media Driver (Broadwell / 5ª gen ou mais recente) ou libva-intel-driver (Haswell / 4ª gen ou anterior), além de utilitários de diagnóstico (libva-utils + gstreamer1-vaapi). Não há botão de remoção — para desfazer, use o terminal.

Driver Moderno: Aceleração de Vídeo Intel (Broadwell / 5ª gen Core+ / Arc)

O pacote intel-media-driver habilita aceleração de vídeo por hardware em iGPUs Intel Broadwell (5ª gen) ou mais recentes — incluindo Coffee Lake, Ice Lake, Tiger Lake, Alder Lake, Raptor Lake, Meteor Lake e as placas dedicadas Intel Arc. Reduz o uso de CPU ao assistir vídeos em 4K, ao usar o navegador e ao editar vídeo.

Driver Legado: Aceleração de Vídeo Intel (7ª gen Core ou anterior)

O pacote libva-intel-driver é o driver legado para iGPUs Intel Haswell (4ª gen), Ivy Bridge (3ª gen), Sandy Bridge (2ª gen) ou anteriores — gerações que o intel-media-driver não cobre. Use este botão apenas se a sua CPU for dessa geração; caso contrário, use o driver moderno acima.

ℹ️ Como saber sua geração: rode lscpu | grep "Model name" no terminal. Core i3/i5/i7 de 4ª geração = "Haswell". 3ª = "Ivy Bridge". 2ª = "Sandy Bridge". Se for 5ª geração (Broadwell) ou mais nova, use o driver moderno acima.
