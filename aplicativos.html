🎨 Suíte Affinity (Photo, Designer, Publisher)

A Affinity não tem versão nativa pra Linux. Este botão abre o instalador da AffinityOnLinux, um projeto da comunidade (não afiliado à Serif/Canva) que prepara um ambiente Wine já configurado pra rodar a Affinity.

⚠️ Você precisa ter comprado e baixado o instalador .exe da Affinity pelo site oficial da Serif/Canva antes de usar isto — o FOF só prepara o ambiente Wine e abre o instalador da comunidade; ele é quem vai pedir o arquivo .exe na hora certa. É um projeto de terceiros: se algo não funcionar no seu hardware, consulte a página de problemas conhecidos deles.
📦 Pré-requisito: PyQt6 é necessário para a interface do instalador. O FOF verifica e instala automaticamente se necessário.

☁️ Sincronização em Nuvem

Ferramentas para sincronizar arquivos com Google Drive, OneDrive, Dropbox e outros serviços.

ℹ️ Configuração das contas de nuvem: o Rclone Manager é uma interface gráfica para o Rclone. Ele permite configurar acesso a Google Drive, OneDrive, Dropbox, S3, e dezenas de outros serviços de armazenamento em nuvem. Após instalar os dois aplicativos, abra o Rclone Manager e siga o guia interno da própria interface para adicionar suas contas. O FOF apenas instala as ferramentas — a configuração das contas é feita por você, dentro do Rclone Manager.
